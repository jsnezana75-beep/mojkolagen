# 5IN1 Beauty Elixir — sajt

Statičan sajt (HTML + CSS), spreman za GitHub Pages.

## Objava na GitHub Pages
1. Napravi novi repozitorijum na github.com (npr. `beauty-elixir`), javni.
2. "Add file" → "Upload files" → prevuci SAV SADRŽAJ ovog foldera (index.html, porudzbina.html, nocturne.css, favicon.svg, robots.txt, sitemap.xml, .nojekyll i folder img). → "Commit changes".
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. Posle 1–2 minuta sajt je na: https://TVOJE-KORISNICKO-IME.github.io/beauty-elixir/

## Posle objave
- U index.html, porudzbina.html, robots.txt i sitemap.xml zameni `https://www.tvojdomen.rs` pravom adresom sajta.
- Sopstveni domen: Settings → Pages → Custom domain.
